# ARCloud デザインシステム

オープンキャンパスで「歩いて見つける」体験に合わせ、ロゴと同じ赤・黄色を使う。既存のモバイル画面の構成と、丸みのある操作部品を引き継ぐ。

## 配色

色の定義は `public/brand/theme.css` に集約し、`app/globals.css` から Tailwind の意味別トークンへ対応づける。AR スキャナーの iframe も同じ CSS を読み込む。

| 基準色 | 値 | 用途 |
| --- | --- | --- |
| コーラル | `#E64B45` | ロゴ由来の補助色・紙吹雪。白地の小さな文字には使わない |
| イエロー | `#F5BF32` | 選択中のフィルター、獲得スタンプ、現在地 |
| ディープレッド | `#B53030` | 主操作、リンク、アイコン、フォーカス |
| キャンバス | `#FFFCF7` | アプリの背景 |
| サーフェス | `#FFFFFF` | カード、入力欄、ナビゲーション |
| インク | `#382C28` | 本文、黄色の上の文字 |

薄赤 `brand-soft` はエラーやメニューの選択、薄黄 `accent-soft` は案内・進捗・獲得済みの状態に使う。補足文字は `muted`、枠線は `hairline` に統一する。色値を画面ごとに追加しない。

## 状態と読みやすさ

- 主操作は `bg-brand text-white`。ホバーは `brand-hover`、押下は `brand-strong`。コーラルに白い小文字は載せない。
- 黄色の面の小さい文字には `ink` を使う。`brand` は黄色の上ではアイコンや大きい文字に使い、黄色の文字を白地に置かない。
- キーボードフォーカスは深赤の 2px アウトラインと 2px の余白で示す。
- 選択状態は `aria-current` / `aria-pressed`、スタンプはアイコン・ラベルでも示す。
- マップの現在地は黄色の円・白い内周・深赤の外周。施設ピンの深赤の吹き出しと形でも区別する。
- AR の案内はカメラ映像上で読める暗い半透明面に白文字、黄色のスキャンアイコンを使う。
- ライトテーマを維持し、OS のダークモードに色を左右されないようにする。動きを減らす設定を尊重する。

## 文字・余白・形

- 欧文は既存の Geist、日本語は OS 標準のゴシック。本文は行高 1.6。
- ホーム見出し 28px、画面見出し 22px、主要ラベル 15〜16px、補足 12〜14px。
- 入力文字は 16px を維持し、iOS の自動ズームを避ける。
- 余白は 4px を基準に、画面左右 16〜20px、セクション間 24px。
- 入力・フィルターはピル型、小さなアイコン面は 12px、カードは 16px の角丸。
- 影は暖色のインクを薄く使う `shadow-card` / `shadow-float`、主要操作は `shadow-action`。

## ロゴ

元のアイコン画像は `assets/brand/arcloud-icon.png` に保存する。ヘッダーは `public/brand/arcloud-icon.png` と `arcloud-wordmark.png` を使い、アイコンは静的 import で変更時に参照URLも更新する。アイコン本体は深赤・黄色を保ち、画面の操作色にも読みやすい深赤を選ぶ。

ブラウザ用の `app/favicon.ico` は 16 / 32 / 48 / 64px、`app/icon.png` は 192px、ホーム画面用の `app/apple-icon.png` は白背景の 180px。いずれも同じ元画像から比率を保って書き出す。
